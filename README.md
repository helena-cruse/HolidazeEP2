Holidaze PE2

Holidaze is a modern accommodation booking application built as my Project Exam 2.

The project allows users to browse venues, view venue details and make bookings. Venue managers can create, edit and manage their own venues and bookings through a separate dashboard.

## Features

- User registration and login
- Browse and search venues
- Venue detail pages with booking calendar
- Prevent double bookings
- Create, edit and delete venues
- Venue manager dashboard
- Profile editing
- Responsive design for desktop, tablet and mobile
- Figma prototypes and style guide

## Built With

- React
- Vite
- Tailwind CSS
- JavaScript
- Noroff Holidaze API
- Netlify

### Install

Clone the repository:

```bash
git clone https://github.com/helena-cruse/HolidazeEP2.git
```

Install dependencies:

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Build project

```bash
npm run build
```

## Deployment

The project is deployed with Netlify.

Live site:
